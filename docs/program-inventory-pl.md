The table below inventories future actionable commitments rather than copying historical allegations, numerical background or claimed outcomes as facts. Introductory values/outline (pages 8–12) and conclusion (74–75) repeat later measures rather than creating an additional proposal denominator. Thematic indexes are navigation, not additional commitments.

The 337 rows include repeated references and related submeasures. **337 is not a deduplicated proposal count and must not be used as a debate-coverage denominator.** `represented` means the substance is visible in the current card summary, paragraphs or implications. `missing-detail` means an additional commitment, named scope, safeguard or parameter is absent or too generic. It does not necessarily call for a new card. Current snapshot was read after the parent added the initial 15 packages.
