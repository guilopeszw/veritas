# Rally comparison

The page offers one event selector per candidate, candidate/city filters for recorded attendance events, and two shortcuts: estimates from the same research institute and the largest reported numeric estimate in the current dataset. The latter includes organizer claims and preserves lower-bound wording; it does not establish the largest event in the campaign or a winner. All sources, methods, times and caveats remain visible. No counts are added or averaged.

On mobile, search belongs to an opaque sticky navigation header. Comparison columns stack. City result rows remain stacked and no longer have a text search.

Validation: build and JavaScript syntax; browser checks of both shortcuts, candidate/city filters, empty results and horizontal overflow. At the tested narrow viewport, document scroll width equals client width; the search button stays within the header while scrolling.
