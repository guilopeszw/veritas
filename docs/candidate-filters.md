# Candidate filters

Dossiers (controversies, transparency, sovereignty, working hours and debate summaries) offer All, Lula and Flávio buttons. Existing proposal, fact-check and rally filters remain in place. Profile pages already concern one candidate.

The selection persists per dossier during navigation in the same browser session. Matching uses explicit candidate metadata and candidateContext entries, never text/name guessing. Shared records and general explanations stay visible, with a visible explanation. Timeline markers hide together with their cards. Empty candidate columns collapse. Native buttons expose pressed state and retain keyboard focus; controls wrap on narrow screens.
