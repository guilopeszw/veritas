## Verification limits and publication status

Direct downloads of both program PDFs return HTTP 403 HTML, including the previously saved files misleadingly named `.pdf`. The completed verification uses the official indexed text and page metadata. It does not claim binary-PDF hashes, visual authentication of every page, document-signature verification, or a historical version identifier.

The transcript evidence combines Aos Fatos narrative transcription, local automatic speech recognition, YouTube captions and preceding visual speaker checks. No independent human listening occurred. Automated transcriptions can share errors; this limitation is not converted into a claim of manual audiovisual validation.

PT had a separate source reviewer; PL was reread by its original coder against the complete source. This is not a blinded independent dual-coder agreement study. The primary agent reread the narrative and matching transcript intervals and reconciled the decisions.

The exact arithmetic is reproducible under this rule. It does not measure quality, feasibility, truthfulness, speaking time or attack time. Different legitimate granularity rules can yield different totals. No unpublished percentage is released automatically: the public build still requires explicit editorial approval.
