# Context and proposal navigation

20 October 2026.

The former “Assuntos” hub is labelled “Entenda a eleição”. It groups events, public positions, transparency, controversies, fact checks and economic explanations. Proposal comparison remains a separate top-level destination.

The health shortcut that opened proposal comparison was removed from the context hub. Navigation labels, accessible names, search suggestions and breadcrumbs use the new name. The existing `#/assuntos`, `#/temas` and `#/debate` routes remain compatible with saved links. Global search can still find both content types; this change does not suppress evidence references within articles.

Acceptance: no direct proposal route in the hub, a distinct Propostas navigation item, unchanged old route resolution, and readable mobile navigation.
